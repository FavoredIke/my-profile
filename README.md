# Isaac Boateng – Personal Portfoliox

A personal portfolio website built to introduce myself, showcase my interests and projects, and provide a way for visitors to get in touch.

## Overview

This project is a responsive personal portfolio developed using HTML, CSS and JavaScript. It features a modern layout, interactive navigation, scroll animations and a contact form with client-side validation.

## Features

- **Home Section:** Introduction, profile image and social media links.
- **About Section:** Personal introduction and skills presentation.
- **Projects Section:** Displays selected projects and technologies.
- **Contact Section:** Contact form with input validation.
- **Responsive Design:** Adapts to desktop, tablet and mobile screens.
- **Mobile Navigation:** Interactive menu for smaller screens.
- **Scroll Animations:** Elements fade into view as visitors scroll.
- **Animated Skill Bars:** Visual representation of selected skills.
- **Dynamic Footer:** Automatically displays the current year.
- **Accessibility:** Includes accessible navigation labels and reduced-motion support.

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone git@github.com:FavoredIke/my-profile.git
   ```

2. Navigate into the project directory:

   ```bash
   cd my-profile
   ```

3. Open `index.html` in your preferred web browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension.

## Current Limitations

- Social media links are placeholders and need to be connected to the appropriate profiles.
- Some projects displayed on the portfolio are planned projects and are not yet completed.
